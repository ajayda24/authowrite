# 0008. AGPL-3.0 license

- Status: Accepted
- Date: 2026-09-27

## Context

Authowrite is a network service meant to be run by many independent hosts. The project's goal is
that improvements stay open, and nobody can turn it into a closed platform.

## Decision

License the code under GNU AGPL-3.0-only.

## Consequences

- Anyone running a modified instance must offer its source to its users.
- Stories and other user content are owned by their authors and are not covered by the code
  license. Per-story content licenses (e.g. CC BY-SA) arrive with forking in V3/V5.
